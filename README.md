# 客韵 · 客家文化全球共创平台

基于三张项目参考素材制作的响应式网站。前端使用 HTML、CSS 和原生 JavaScript，部署到 https://czx1220.github.io/hakka-culture/ 。

## 本地预览

运行 `python3 -m http.server 8000`，访问 http://localhost:8000 。网页无需安装依赖或构建。

## 资源库

支持分类、搜索、详情、下载/外链访问和本机收藏。内置三份原创入门资源；真实社区资源由 GitHub 公开 Issues 自动发布成静态目录，访客正常浏览无需直接请求 GitHub API；“刷新资源”可查询实时审核结果。

投稿者在网页填写信息后跳转 GitHub，登录并提交。可以填写 HTTPS 公开链接，也可留空，在下一步 GitHub 正文的“资源链接”区域拖入文件，保留自动生成的附件链接。文件托管于 GitHub 附件或投稿者提供的外部存储，上传需要 GitHub 登录；本站不提供匿名直传。

管理员在仓库 Issues 中审核资源内容、来源、授权和链接，移除 `resource-pending` 标签并加上 `resource-approved` 标签。保持 Issue 为 open，GitHub Actions 会自动更新网站目录，部署完成后即可看到，也可点“刷新资源”即时查看。移除 approved 标签或关闭 Issue 即下架。投稿本身公开可见，审核决定是否进入网站资源库。GitHub 未登录 API 请求可能受额度限制，网页会显示同步失败并保留已加载资源。

页面表单及 `.github/ISSUE_TEMPLATE/resource.yml` 使用相同字段。为了避免注入，社区内容按文本渲染，仅接受 HTTPS 链接。收藏只存于当前浏览器，并非跨设备账号收藏。

## AI 作曲

工作台提供灵感预设、乐器/风格/时长选择、音频播放与下载，以及生成后投稿入口。

- **旋律演示**：浏览器本地规则合成的原创五声音阶演示音频，不是 AI 模型或真实客家录音。
- **AI 作曲**：独立 Node.js 服务代理 fal 的 Stable Audio 2.5 纯音乐生成，支持排队状态与重试查询。目前未配置密钥、未部署后台，因此线上明确显示未开通。

接入步骤见 [server/README.md](server/README.md)。GitHub Pages 只提供静态前端，不能运行该后台。可在自己的电脑调试；正式运行需独立在线服务。不得在 `config.js` 或前端中存放提供商密钥。

## 其他内容与发布

展演与文创板块仍为概念展示，没有接入真实直播或交易。平台规模数字来自参考素材，非本站实际资源量。山水土楼图为项目原创 SVG 艺术示意，文创袋由 CSS 绘制。Google Fonts 不可访问时回退系统字体。

main 推送后由 GitHub Actions 自动发布。工作流只上传网页文件和 assets，不上传后台、测试、环境变量或原始参考图片。

## 资源共享使用方法

1. 打开网站“资源共享”，点“分享资源”，填写名称、分类、作者、介绍和许可。
2. 有公开链接就填链接；没有链接就留空，点击“前往 GitHub 提交”。登录 GitHub 后，把文件拖到正文的“资源链接”区域，删除提示文字，等待上传完成，再提交 Issue。
3. 管理员打开仓库 Issues 审核，添加 resource-approved 标签。约一至数分钟后网站自动更新。
4. 访客不需登录即可浏览、搜索、下载资源；音视频直链可在详情里播放。第三方页面链接通过“打开资源链接”访问。

只有真实审核通过的投稿会出现在社区列表，目前初始内容为三份平台原创资源，没有伪造用户投稿。原始素材版权请按各资源说明使用。
